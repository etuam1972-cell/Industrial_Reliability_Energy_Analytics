# Industrial Reliability & Energy Analytics

Projeto de portfólio com dados 100% sintéticos para conectar manutenção, confiabilidade, produção, energia, processo, perdas e causa raiz.

## Tabelas
- DIM_MAQUINA
- DIM_CAUSA_RAIZ
- FAT_MANUTENCAO
- FAT_PRODUCAO
- FAT_ENERGIA
- FAT_PROCESSO
- FAT_PERDAS
- FAT_ACAO_MELHORIA

## Objetivo
Investigar a cadeia: Falhas → MTBF → MTTR → Disponibilidade → Produção → Energia → Perdas → Causa raiz → Ação de melhoria.

## Ferramentas sugeridas
Excel / Power Query, SQL, Power BI e Python.

## KPIs sugeridos
MTBF, MTTR, disponibilidade, OEE, produção, refugo, horas de parada, kWh, kWh/peça, custo de manutenção, custo de perdas e Pareto de causas.

## Aviso
Todos os dados são fictícios e foram criados exclusivamente para fins educacionais e de portfólio. Não representam dados de nenhuma empresa real.
